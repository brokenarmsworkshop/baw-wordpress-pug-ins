# BAW WordPress Plugins

Dépôt des extensions WordPress développées pour Broken Arms Workshop.

## Extensions

- [BAW Bundle Importer](baw-bundle-importer/) — import de packs produits WooCommerce en brouillon, produits simples ou variables.
- Version validée sur la boutique : **0.4.0**.
- Archive installable : [BAW_Bundle_Importer_PLUGIN_v0.4.0.zip](dist/BAW_Bundle_Importer_PLUGIN_v0.4.0.zip).

Chaque extension est conservée dans son propre dossier avec son code source et sa documentation. Les données commerciales importées restent à contrôler avant publication.
